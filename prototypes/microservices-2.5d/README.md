# 微服务 2.5D 阅读原型

用现有的 `tests/fixtures/traditional-microservices.diagram.json` 展示平面与立体阅读方式。总览保留原有 12 个节点、11 条连接及节点说明；每个模块都可进入内部视图，查看新增的教学拆解。关联高亮复用项目的 `GraphIndex` / `findRelated`。

## 查看

需要 Node.js 24。在此目录运行：

```bash
npm ci
npm run build
```

在浏览器打开 `dist/index.html`。HTML 内嵌 Three.js、样式和示例数据，不需要 CDN 或网络字体。也可以启动本机预览：

```bash
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:8766`。

## 交互

- 顶部切换“平面 / 立体”，保留已选择节点与高亮范围。
- 点击总览中的任意模块，进入其内部结构；也可从右侧列表选中模块，再点击“进入模块内部”。列表选择还支持查看总览中的职责与关联。
- 内部视图点选节点，查看职责、输入输出和直接连接。点击面包屑“系统总览”返回，并恢复此前模块选择与高亮范围。
- 点击“聚焦节点”将相机移到对应位置；内部视图也支持双击节点聚焦。
- 点击“上游 / 下游”，沿原始有向连接查询所有可达节点；“全部”恢复完整显示。
- “视角复位”恢复当前模式的默认相机，保留节点选择与高亮；Escape 清除选择，无选择时再次按 Escape 返回总览。
- 立体模式拖动旋转，平面模式拖动平移；滚轮缩放，右键平移。窄屏使用节点列表定位，也可双指缩放和平移。

## 范围

这是针对该教学示例的原型。`src/module-details.ts` 为 12 个模块提供内部职责和连接，全部标为 `assumed`，未从真实服务代码提取，不代表现有业务系统的实现。详情面板和画布持续展示教学示意标记。

展示泳道、节点位置和部分连线路径采用明确配置，没有接入通用三维自动布局；内部视图按接入、处理、结果三组排列。空间高度不是原始模型中的架构事实。示例关系均为假设，仍需核查。

原型依赖与构建独立于正式 Skill。WebGL 不可用时可通过节点列表查看说明和连接；正式 SVG / PNG / JPEG 导出仍由原有阅读器提供，原型没有新增静态导出。
