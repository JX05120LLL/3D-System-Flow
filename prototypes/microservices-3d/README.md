# 微服务 3D 架构沙盘原型

使用现有微服务教学示例，在全屏 3D 场景中展示 12 个系统模块，以及订单、库存、支付服务的 16 个内部组件。短名牌附在模型上，组件形态表达职责；详细说明在点击后按需展开。旧版 `../microservices-2.5d/` 保留用于对照。

本目录保留固定示例原型。可复用能力已接入正式 Skill：使用 `system-flow/scripts/generate.mjs --renderer 3d` 生成其他架构，数据格式与验收见 [空间建模说明](../../system-flow/references/spatial.md)。

## 查看

需要 Node.js 24。在本目录运行：

```bash
npm ci
npm run build
python -m http.server 8767 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:8767/`。`dist/index.html` 内嵌 Three.js、样式和数据，没有 CDN、网络字体或外部模型。

## 操作

- 拖动旋转，滚轮缩放，右键平移；顶部图标提供俯视/立体切换、视角复位和全屏。悬停图标可查看操作名称。
- 悬停模型强调当前对象；点击订单、库存或支付服务展开内部组件。三个剖面可同时保留，外壳按钮独立收拢当前服务。
- 点击内部模型或名牌聚焦组件，浮窗显示简短职责；信息按钮展开完整说明。浮窗中的图标提供聚焦、上下游高亮、恢复全部关系和模块隔离。
- 顶部模块选择按钮打开按需列表，支持键盘访问全部 28 个对象；内部组件使用当前服务的关系图，上下游高亮不混入其他服务的内部关系。
- 点击返回总览或按 Escape 收拢全部剖面、清除选择并复位；单独关闭职责浮窗保留已经展开的服务。
- 底部选择正常下单、库存不足或支付失败。镜头和移动标记随步骤进入内部组件；每步 2.2 秒，暂停冻结当前进度；下一步/上一步推进或回看后保持暂停。三个场景分别为 16、10、15 步。
- 重置或切换演示场景清空播放进度并返回总览。页面进入后台时自动暂停，恢复播放不会补算暂停时间。
- 用户手动选择模块、查看关联、展开完整职责或返回总览会暂停播放，便于检查；再次播放恢复当前教学步骤。倒退会收拢尚未进入的服务，支付失败的释放步骤会重新经过库存内部组件。
- 焦点不在按钮或输入控件时，空格播放/暂停，左右方向键前后单步；Escape 先关闭模块列表，再返回总览。

## 数据与范围

总览来自 `../../tests/fixtures/traditional-microservices.diagram.json`，保留 12 个节点和 11 条原始关系。内部说明复用旧原型的教学拆解：订单 6 个组件，库存和支付各 5 个组件。库存使用操作识别器、双向调整器、状态货架等形态；支付使用关联链环、收单通道、流水账本等形态。空间位置、体积、端口与剖面均是展示模型，不表示真实部署规模、延迟或机器位置。

演示步骤在 `src/demo.ts` 中显式编排，并参考既有下单流程示例。响应方向和补偿路径用于讲解，没有向正式图数据补写推断关系。成功分支的异步通知在同步响应后讲解，不规定真实消息发布时机；库存不足取消待确认订单，不调用支付或释放库存；支付失败取消订单并请求释放已预留库存。

本原型全部内容均为教学示意，没有真实网络业务请求、支付、库存变更或实时监控接入。三个业务服务有完整空间剖面，其他模块提供概览与关系；此目录使用固定空间配置，不提供通用生成或静态导出。正式 Skill 的通用布局与生成入口独立于本原型。

WebGL 不可用时，可以通过按需模块列表和演示步骤阅读职责说明；3D 控件禁用。系统支持键盘操作和减少动态效果设置。

## 检查

```bash
npm run typecheck
npm test
npm run build
```

2026-10-11 本机验收：类型检查、24 项模型/状态测试和单文件构建通过。Windows Chrome 实际验证了全屏场景、28 个对象、三个独立剖面和全部 16 个内部组件的选择与职责、模型本体点击、悬停、上下游高亮、隔离、镜头旋转/缩放/复位及全屏。

三个分支全部前后单步通过，累计展开和倒退收拢正确。展开职责后等待 2.5 秒，播放进度保持不变；手动检查库存后可以恢复原支付步骤。正常下单实际自动播放 16 步用时约 35.4 秒；三个分支重复播放/重置后，已预热几何计数保持 374，此计数不代表完整 GPU 内存采样。

浏览器加载后离线交互通过，正常 WebGL 场景未发现脚本错误、控制台警告或外部请求。375/320px 为 Chrome 视口模拟，尚未在实体手机验收；WebGL 失败通过拦截 `getContext` 模拟，减少动态效果通过浏览器媒体设置模拟验证。

最终构建复验确认：支付失败的释放步骤不再被展开屋顶遮挡；320px 下聚焦支付内部组件时，所属五个组件完整位于视野。窄屏整舱取景时名牌文字仍较小，可放大或点击职责卡阅读；模拟 WebGL 降级卡片不越界。

本机证据保存在忽略的 `output/playwright/`：`immersive-interaction-results.txt`、`immersive-demo-results.json`、`immersive-demo-autoplay-results.json`、`immersive-ui-results.txt` 及对应截图。未验证 `file://` 运行、其他浏览器、长期 GPU 内存变化或真实业务环境。Three.js 的 MIT 许可证保留在生成 HTML 中。
